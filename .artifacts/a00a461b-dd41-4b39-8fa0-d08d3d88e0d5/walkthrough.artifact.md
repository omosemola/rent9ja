# Mobile View: RentNaija

The RentNaija mobile app is a premium Flutter-based platform for property discovery in Nigeria. It features a sophisticated design system optimized for high-end real estate listings.

## Key Screens & Features

### 1. Home Screen (Discovery)
- **Top Bar**: Branding with a custom home icon and notification bell with badge.
- **Search & Filter**: A prominent rounded search bar ("Search for apartments...") with a filter toggle.
- **Featured Carousel**: Large, high-impact property cards with gold "Featured" badges and favorite toggles.
- **Quick Categories**: Horizontal chips for filtering by "Apartment", "Duplex", "Studio", etc.
- **Popular Cities**: Visual cards for Lagos, Abuja, Port Harcourt, etc., with listing counts.
- **Newest Listings**: A vertical list of the latest properties with "New" tags.

### 2. App Navigation
The app uses a Material 3 bottom navigation bar with five main sections:
- **Home**: Discovery and featured listings.
- **Search**: Advanced filtering and map views.
- **Saved**: User's favorite properties.
- **Chat**: Real-time communication with property owners/agents.
- **Profile**: User settings and account management.

### 3. Visual Identity
- **Primary Color**: Deep Emerald Green (`#0A6847`) - symbolizing growth and luxury.
- **Accent Color**: Warm Gold (`#D4A017`) - highlighting premium features.
- **Typography**: Geometric "Outfit" font for a modern, clean feel.
- **Shapes**: Soft rounded corners (16-20px) on all cards and buttons.

## Technical Stack
- **Framework**: Flutter (Material 3)
- **State Management**: Bloc/Cubit
- **Navigation**: GoRouter
- **Theming**: Custom `AppTheme` with full Dark Mode support.
